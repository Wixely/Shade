# Monitor layout controls

- Implemented/reviewed: 2026-09-10; next review: 2026-09-17
- Owner: Codex
- Source: User request for monitor-shaped toggle buttons, a global slider, collapsed individual controls and scrolling

## Behavior

The Global dimming slider sits above a map of the actual Windows desktop arrangement. A common scale preserves screen proportions, portrait orientation, relative positions, gaps and negative coordinates. A small inset separates touching screen buttons. Maps with extreme size differences retain usable buttons and scroll instead of stretching individual monitors.

Click a screen to enable or disable its dimming. Enabled screens use the current global value when linked, or their individual value when independent. Buttons show screen number, on/off state and dimming percentage. Numbers link map buttons to Advanced rows; all commands still use monitor IDs, not those display numbers.

Correction on 2026-09-10: the user's independent-global requirement supersedes the initial interpretation that global changes enabled every screen and showed mixed levels. Global now affects only enabled screens with **Use global** selected. Its value stays independent of individual changes and restoration. Global at 0% preserves enabled intent; disabling a screen or emergency restoration clears that intent so later global changes cannot revive it.

Advanced includes a **Use global** switch per screen. Unlinking freezes its current intensity; linking applies global only if the screen is already enabled. Adjusting an individual slider makes that screen independent and retains the original behavior of enabling it for nonzero values. New screens start disabled. The subsequent [buildout](buildout-2026-09-10.md) added persistence of global value, membership, individual levels and enabled-at-zero intent for trusted identities, with native restart/reconnect verification.

Advanced is collapsed initially and exposes the original per-screen sliders, identity/geometry details and restore buttons. It is a keyboard-operable disclosure with expanded state. Closing it removes those controls from the accessible layout. The global slider stays above the scrolling screen/Advanced area; the map also supports overflow scrolling. Extremely short windows can scroll the outer container as well.
