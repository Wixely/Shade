## Exact accessibility stopping point

Completed fixes include focus clipping/reveal, safe off-screen activation, exact ordinary text values, protected password reads, Windows editable values/property notifications, and engine-only immutable editor snapshots and path-based selection.

`CupriDocument.GetAccessibleTextState` and `AccessibilitySelectText` exist and are tested. They are not connected to native text-range interfaces yet. The existing IME state API includes raw passwords and must not be published as an accessibility snapshot.

The last attempted text geometry patch failed to apply. `AccessibleTextRectangle`, `GetAccessibleTextBounds` and `GetAccessibleTextOffset` do not exist at this checkpoint. There is no half-applied geometry implementation to resume. Native text-range bounds, point mapping, range navigation and events remain to be designed/implemented and tested. Do not describe the current editor APIs as complete screen-reader support.
